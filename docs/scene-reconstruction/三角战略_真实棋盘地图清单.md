# 《三角战略》真实战斗棋盘地图清单

核查日期：2026-10-24。范围：本机安装包；下文中文为资源名释义，不冒充官方地点译名。

## 结论与口径

- **战斗表登记且有完整静态引用链：89 个关卡包 → 46 份 WB 棋盘 → 26 个场景家族。**其中主线/路线关卡包 54 个，模拟战 35 个。关卡包数不等于一条路线的战斗场数。
- **另有 1 份流程用途待确认的 Ship02 棋盘**和 1 份历史战斗棋盘（旧版港口），均不计入正式战斗表；已识别战斗引用的 WB 共 48 份。
- 按 `(x, y, Height, MapAttribute)` 去重，已登记部分为 **42 套基础格子布局**，含候选为 44 套；这不代表机关、出击点、运行时状态也相同。
- 原包 Map 目录有 1305 个 `.umap`、167 个符合旧 `_WB` 正则的关卡；不能把剧情、探索、预览、世界地图和测试资源全算战场。
- 正式判定：`NeweraBattleLevel` → `UWorld.StreamingLevels / WorldAsset` → 非 StandBy 的 WB → 格子，并核对 `levelWhiteBoxAsset` 与 `GOP_Battle_Info`。旧关另查战斗准备、脚本及直接流送 WB；本清单是静态核查，未逐关通关实测。

## 容易数错的地方

- **不要按后缀直接排除。**`sqec_battle` 没有数字后缀但正式登记；`ms01_x01_old_battle_01` 是有战斗准备的历史关，缺 WBAsset 时仍可从流送 WB 还原。
- **文件名带 test 不一定是测试图。**第 1 章与 `sq03_battle_01` 使用 `A1_EX_Harbour01test_WB/GFX`；无后缀的 `A1_EX_Harbour_WB` 属于旧入口，不能替换。`A1_EX_Villagesano_WB` 也被正式入口 `ms12_x23_battle_01` 引用。
- **WB 不同未必布局不同。**`A0_IN_Mine34_WB` 与三个 `A0_IN_Mine34_sq09_0{1,2,3}_WB` 的上述四字段一致；`C0_EX_Field2_WB` 与 `C0_EX_Field2_sqec_WB` 也一致，仍保留独立资源身份。
- **一图可有多种画面状态。**`A0_EX_Garden02_WB` 在 `ms02_x02_battle_01` 带 `A0_EX_Garden_B_OTH_ms02_x02`，在 `battle_02` 不带；不能按 GFX、OTH 或工程的 `SB_*` 数量统计原版棋盘。`SB_*` 是还原工程命名。
- **缺 GFX 不能冒充已确认。**`ms12_x23_battle_01` 直接流送的画面层只有 StandBy；现有工程采用同目录 `A1_EX_Village_GFX` 是推断，需另做运行时核对。
- **缺省属性要继承 CDO。**`BP_BaseBlock_C` 的 `Height` 默认是 1，实例省略时不能写成 0。`sq01_battle` 无对应当前地图包，只保留为未解析旧名。
