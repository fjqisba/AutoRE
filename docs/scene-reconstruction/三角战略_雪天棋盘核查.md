# 《三角战略》雪天战斗棋盘核查

核查对象：本机原包配置、地图缩略图、雪粒子资源，以及当前 Godot 生成器。

## 结论

- 正式战斗表中找到 **7 个初始天气为 SNOW 的入口、5 份 WB、2 个主要外景家族**；这不是全部可通过技能或事件变成雪天的场景数量。
- 这些 WB 已在当前 49 个场景目录内。雪粒子 P_EFF_Snow00 本次成功解析（29 个导出对象），三张原版雪天地图缩略图也成功解码，没有发现这批雪天资源仍未解密的证据。
- 当前批量生成器按 WB + 表现层合并，未把入口天气、时间与风作为状态身份；通用地表 shader 缺少积雪分支，雪粒子尚未接入。因此地图资源覆盖不等于雪天表现覆盖。
- 既有全包扫描记录覆盖已挂载的 1,310 个地图包；这只针对该安装版本及挂载范围，不证明所有版本或未挂载包均无遗漏。

## 还原缺口

按入口保留天气/时间/风变体；恢复积雪底色、法线、PBR、表面坡度与遮罩；接入落雪粒子、风向和对应日夜光照。之后分别验证雪夜街区、雪夜要塞和白昼要塞，不能沿用静态晴天截图的通过结果。
